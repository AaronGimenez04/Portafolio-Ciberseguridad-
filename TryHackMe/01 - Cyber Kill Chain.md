## 1. ¿Qué es Cyber Kill Chain?

Es un modelo desarrollado por Lockheed Martin que divide un ciberataque en siete fases. Permite entender el comportamiento del atacante y establecer medidas de defensa en diferentes puntos del ataque.

## 2. Las siete fases

1. **Reconnaissance (Reconocimiento):** el atacante recopila información sobre su objetivo.
    
2. **Weaponization (Preparación del arma):** prepara o modifica una herramienta maliciosa para el ataque.
    
3. **Delivery (Entrega):** hace llegar el archivo o contenido malicioso a la víctima.
    
4. **Exploitation (Explotación):** aprovecha una vulnerabilidad para ejecutar acciones en el sistema.
    
5. **Installation (Instalación):** instala malware o una puerta trasera para mantener el acceso.
    
6. **Command and Control (C2):** establece comunicación con el sistema comprometido para controlarlo.
    
7. **Actions on Objectives (Acciones sobre el objetivo):** realiza sus objetivos, como robar información o acceder a otros sistemas.
    

## 3. ¿Cómo se puede utilizar para defenderse?

- Filtrar correos y archivos sospechosos para dificultar la entrega.
    
- Mantener los sistemas actualizados para reducir las vulnerabilidades.
    
- Utilizar antivirus, EDR y herramientas de detección.
    
- Supervisar las conexiones de red para identificar comunicaciones sospechosas.
    
- Registrar los eventos para investigar posibles incidentes.
